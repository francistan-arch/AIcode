🔄 Sequence Flow Diagram

How your Node.js application interacts with 2C2P Hosted Payment Page and Webhooks: 

1. Customer clicks "Checkout" on Merchant Frontend.
2. Merchant Server signs payload into JWT with Secret Key (HS256).
3. Merchant Server posts JWT to 2C2P Payment Token API (/payment/4.3/paymentToken).
4. 2C2P returns paymentToken & webPaymentUrl (Hosted Payment Page).
5. Customer is redirected to webPaymentUrl (Credit Card, PromptPay, E-Wallet).
6. 2C2P sends asynchronous notification (Webhook) to Merchant backendReturnUrl.
7. Merchant verifies Webhook JWT signature, updates order status, and returns 200 OK.
8. 2C2P redirects Customer browser back to Merchant frontendReturnUrl.

🔑 Step 1: Install Dependencies & Sign Request JWT

npm install jsonwebtoken axios

// lib/2c2p.js
const jwt = require('jsonwebtoken');

function generatePaymentTokenJwt(payload, secretKey) {
  // Sign payload using HMAC SHA-256 (HS256)
  return jwt.sign(payload, secretKey, { algorithm: 'HS256' });
}

🌐 Step 2: Request Payment Token & Redirect User

const payload = {
  merchantID: 'JT01',
  invoiceNo: 'INV-2026-001',
  description: 'Tech Gadget Order',
  amount: 2500.00,
  currencyCode: 'THB',
  frontendReturnUrl: 'https://yourdomain.com/payment-complete',
  backendReturnUrl: 'https://yourdomain.com/api/webhook/2c2p'
};

const tokenJwt = jwt.sign(payload, SECRET_KEY, { algorithm: 'HS256' });
const response = await axios.post('https://sandbox-pgw.2c2p.com/payment/4.3/paymentToken', {
  payload: tokenJwt
});

const decodedResp = jwt.verify(response.data.payload, SECRET_KEY);
if (decodedResp.respCode === '0000') {
  // Redirect customer to 2C2P hosted checkout page
  res.redirect(decodedResp.webPaymentUrl);
}

📩 Step 3: Handle Webhook Notifications (Backend Return URL)

app.post('/api/webhook/2c2p', (req, res) => {
  const { payload } = req.body;
  const decoded = jwt.verify(payload, SECRET_KEY);

  if (decoded.respCode === '0000') {
    // Payment Successful! Update order in database
    console.log(`Order ${decoded.invoiceNo} Paid! Transaction Ref: ${decoded.transactionRef}`);
  }
  
  res.status(200).json({ status: 'OK' });
});
