✈️ 2C2P PACO (Payment Air Controller) Architecture

PACO is 2C2P's enterprise payment orchestration engine providing smart acquirer routing, 3DS authentication, and cost optimization: 

// PACO Payment Request Structure (lib/paco.js)
const pacoPayload = {
  partnerId: 'PACO_DEMO_01',
  externalReferenceId: 'PACO-REF-INV-2026-101',
  merchantReferenceNumber: 'INV-2026-101',
  description: 'AeroPulse Headphones',
  amount: 2490.00,
  currency: 'THB',
  routingPreference: {
    smartRoutingEnabled: true,
    costOptimization: true
  },
  threeDSecure: { deviceChannel: 2 }
};

🚨 PACO Error Code Specifications

PACO categorizes errors into Business Exceptions (`PC-Bxxxxxx`) and Technical System Errors (`PC-Txxxxxx`): 

• PC-0000 : Success / Authorized
• PC-B00101 : Business Logic State Exception
• PC-T050020 : Technical Routing Error (No route found for payment channel)
