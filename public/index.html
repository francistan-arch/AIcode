⚡ Silent Sign-Then-Encrypt Flow

When customer clicks Proceed to Checkout, the backend signs the payment payload using merchant_signing_private.pem with algorithm PS256, encrypts the inner JWS using 2C2P's public key 2c2p_public_encryption.pem with algorithm RSA-OAEP, and dispatches the JWE string over Content-Type: application/jose to 2C2P.
