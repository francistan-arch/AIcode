⚡ Silent RS256 Signed Payment Request

When customer clicks Proceed to Checkout, the backend signs the payment payload using RSA Private Key (`private.pem`) with algorithm `RS256`, calls 2C2P API, and silently redirects to the payment page.

  partnerId: 'PACO_PARTNER_DEMO',
  externalReferenceId: 'PACO-TXN-REF-1001',
  merchantReferenceNumber: 'INV-1001',
  amount: 349.00,
  currency: 'MYR',
  paymentType: 'PACO_HOSTED_PAYMENT_PAGE',
  signatureAlgorithm: 'RS256'
